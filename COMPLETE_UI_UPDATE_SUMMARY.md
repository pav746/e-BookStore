### Color System
```
Primary Yellow   #FFCE1A  → Buttons, highlights
Secondary Navy   #0D0842  → Text, headers
Accent Red       #FF5841  → Hovers, alerts
Light Gray       #F3F3F3  → Backgrounds
Dark Black       #1a1a1a  → Dark text
```

### Animations
```
fadeIn       → Smooth appearance
slideInLeft  → Content from left
slideInRight → Content from right
float        → Gentle motion
pulse        → Attention grab
hover-lift   → 8px elevation
```

### Typography
```
Headers     → Montserrat Bold
Body Text   → Nunito Sans
Sizes       → 12px to 56px scale
Weights     → 400, 600, 700, 900
```

### Spacing
```
Base Unit   → 4px
Scale       → 4, 8, 12, 16, 20, 24, 32, 40, 48, 64
Applied     → px, py, mb, gap, etc.
```

## 🎓 Design System

### Color Philosophy
- **Primary** (Yellow) - Action, energy
- **Secondary** (Navy) - Trust, professionalism
- **Accent** (Red) - Urgency, attention
- **Light** (Gray) - Subtle backgrounds
- **Dark** (Black) - High contrast text

### Typography Philosophy
- **Headers** - Bold, modern (Montserrat)
- **Body** - Clean, readable (Nunito Sans)
- **Hierarchy** - 6-level scale
- **Contrast** - Good readability

### Spacing Philosophy
- **Consistency** - 4px base unit
- **Breathing room** - Generous whitespace
- **Hierarchy** - Larger for important
- **Alignment** - Perfect grid system
