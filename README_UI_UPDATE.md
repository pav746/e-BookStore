- Good breathing room

## 🎯 Design System

### Colors
```
🟨 Primary Yellow:   #FFCE1A (Buttons, highlights)
🟦 Secondary Navy:   #0D0842 (Text, headers)
🟥 Accent Red:       #FF5841 (Hovers, alerts)
⬜ Light Gray:       #F3F3F3 (Backgrounds)
⬛ Dark Black:       #1a1a1a (Dark text)
```

### Shadows
- Small: `0 1px 2px rgba(0,0,0,0.05)`
- Medium: `0 4px 6px rgba(0,0,0,0.1)`
- Large: `0 10px 25px rgba(0,0,0,0.15)`

### Animations
- Transition duration: 300ms
- Timing: cubic-bezier(0.4, 0, 0.2, 1)
- Hover lift: 8px elevation
